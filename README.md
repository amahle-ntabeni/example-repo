# String Manipulation

A Python program that accepts a sentence from the user and performs different string manipulation operations, including finding the length of the sentence and modifying the string.

## Installation

No additional packages are required to run this program.

Make sure Python is installed on your computer.

## Usage

1. Open PowerShell or a terminal.
2. Navigate to the folder containing `manipulation.py`.
3. Run the program using:

`python manipulation.py`

4. Enter a sentence when prompted.

## Example

### Input

I am so hungry

### Output

Length of sentence: 14
I am so hungr@
yrg
I amry
